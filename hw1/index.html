Mini Checklist

S3 Static Hosting, Animal-Powered Edition

  1. Create an S3 bucket (bonus points if it has a beaver/ blobfish name).
  2. Disable “Block all public access” for the bucket (carefully 👀).
  3. Upload this file as index.html.
  4. In Properties → Static website hosting, enable it and set index.html as the index document.
  5. Open the website endpoint. If it looks moist and chaotic, success.

Pro move: later, point a custom domain at it with Route 53 & CloudFront. Blobfish approves this message.
